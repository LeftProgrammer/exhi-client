# 渝水新景 + 领导关怀 · 中控通信协议

> 本文件由项目开发方定义，供中控平台按此格式发送指令。
> 协议基于 WebSocket（UEC 转发服务），消息体为 JSON。

---

## 一、中控 → 设备（接收指令）

设备连接 WS 后，监听中控发来的消息，根据 `cmd` 字段执行操作。

| 操作           | 消息格式                                                              | 说明                       |
| -------------- | --------------------------------------------------------------------- | -------------------------- |
| **回首页**     | `{ "cmd": "home" }`                                                   | 无论当前在哪，返回首页     |
| **进渝水新景** | `{ "cmd": "goto", "target": "yushui" }`                               | 进入渝水新景板块           |
| **进领导关怀** | `{ "cmd": "goto", "target": "leaders" }`                              | 进入领导关怀板块           |
| **切换分类**   | `{ "cmd": "category", "id": "1" }`                                    | 在当前板块切换右侧分类菜单 |
| **下一页**     | `{ "cmd": "page", "action": "next" }`                                 | 当前分类下一张图片         |
| **上一页**     | `{ "cmd": "page", "action": "prev" }`                                 | 当前分类上一张图片         |
| **直接定位**   | `{ "cmd": "goto", "target": "leaders", "category": "1", "index": 0 }` | 直接跳到指定板块+分类+条目 |

### 字段说明

- `cmd` —— 指令类型：`home` / `goto` / `category` / `page`
- `target` —— 板块标识：`yushui`（渝水新景）/ `leaders`（领导关怀）
- `id` —— 分类标识（领导关怀下分类：`1`、`2`）
- `action` —— 翻页方向：`next` / `prev`
- `category` —— 分类标识（与 `id` 同义，用于 `goto` 直接定位）
- `index` —— 条目索引（从 0 开始）

## 二、设备间互相发送（多屏互联）

支持主屏向指定副屏发送控制消息。

### 发送方式

底层通过 UEC WS 转发，`hub.json` 中 `id` 和 `target` 为 WS 连接身份标识，不影响设备间点对点发送。

**单设备发送：**

```typescript
const control = useControl()
control.sendTo('screen-2', { cmd: 'goto', target: 'yushui' })
```

**广播多设备：**

```typescript
;['screen-2', 'screen-3', 'screen-4'].forEach((id) =>
  control.sendTo(id, { cmd: 'goto', target: 'yushui' })
)
```

### WS 消息格式

设备间发送的消息会被包裹为 `{ to, msg }`：

```json
{
  "to": "screen-2",
  "msg": "{ \"cmd\": \"goto\", \"target\": \"yushui\" }"
}
```

接收方副屏的 `useRemoteControl` 会自动解析 `msg` 中的 `cmd` 字段并触发对应 handler。

## 三、WS 连接配置

项目包 `hub.json` 配置：

```json
{
  "url": "wss://www.zzqxs.cn/uec/UECServer/ws/webSocketServer.do",
  "transport": "uec",
  "id": "yushui",
  "target": "yushui"
}
```

- `id` —— 本设备身份标识（部署时按实际设备分配唯一 ID）
- `target` —— 默认消息接收方（中控平台 ID）
- 心跳间隔：20 秒
- 重连间隔：3 秒（指数退避，最大 30 秒）

## 四、项目交互说明

### 首页

- 两个卡片：渝水新景、领导关怀
- 点击卡片进入对应板块

### 二级页（板块页）

- **右侧菜单**（领导关怀有，渝水新景无）：切换分类
- **底部按钮**：上一页 / 下一页 / 回首页

---

## 五、注意事项

1. 中控发送 `category` 和 `page` 指令前，设备需已处于某个板块（`section` 页），否则忽略。
2. `goto` 指令可直接定位到板块+分类+条目，无需先发送板块跳转。
3. 所有消息通过 UEC WebSocket 服务转发，设备仅接收发给自己 `id` 的消息。
4. 部署时每个设备的 `hub.json` 中 `id` 需唯一，避免消息串线。
