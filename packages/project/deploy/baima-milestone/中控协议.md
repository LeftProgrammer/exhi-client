# 白马 milestones · 中控通信协议

> 本文件由项目开发方定义，供中控平台按此格式发送指令。
> 协议基于 WebSocket（UEC 转发服务），消息体为 JSON。

---

## 一、中控 → 设备（接收指令）

设备连接 WS 后，监听中控发来的消息，根据 `cmd` 字段执行操作。

| 操作 | 消息格式 | 说明 |
|------|---------|------|
| **回首页** | `{ "cmd": "home" }` | 回到第 1 页（page1） |
| **跳到指定页** | `{ "cmd": "goto", "index": 2 }` | 跳到第 index+1 页（index 从 0 开始） |
| **下一页** | `{ "cmd": "page", "action": "next" }` | 向后翻一页 |
| **上一页** | `{ "cmd": "page", "action": "prev" }` | 向前翻一页 |
| **直接定位** | `{ "cmd": "page", "index": 3 }` | 直接跳到第 index+1 页 |

### 字段说明

- `cmd` —— 指令类型：`home` / `goto` / `page`
- `index` —— 页码索引（从 0 开始，范围 0~4，对应 page1~page5）
- `action` —— 翻页方向：`next` / `prev`

### 页面索引对照

| 索引 | 页面 | 内容 |
|------|------|------|
| 0 | page1 | 参建单位·科学组织 |
| 1 | page2 | 筹建期 |
| 2 | page3 | 第一阶段 |
| 3 | page4 | 第二阶段 |
| 4 | page5 | 第三阶段 |

---

## 二、设备间互相发送（多屏互联）

支持主屏向指定副屏发送控制消息。

### 发送方式

```typescript
import { useControl } from '@baima-milestone/composables/useControl'
const control = useControl()

// 让副屏跳到第 3 页
control.sendTo('screen-2', { cmd: 'goto', index: 2 })

// 广播
['screen-2', 'screen-3'].forEach(id =>
  control.sendTo(id, { cmd: 'page', action: 'next' })
)
```

## 三、WS 连接配置

项目包 `hub.json` 配置：

```json
{
  "id": "milestone",
  "target": "milestone"
}
```

- `id` —— 本设备身份标识（部署时按实际设备分配唯一 ID）
- `target` —— 默认消息接收方（中控平台 ID）
- 心跳间隔：20 秒
- 重连间隔：3 秒（指数退避，最大 30 秒）

---

## 四、项目交互说明

本项目为 5 页幻灯片轮播，支持键盘 1~5 直接跳转、左右翻页、无操作自动回首页。

---

## 五、注意事项

1. `index` 超出 0~4 范围会被忽略。
2. 翻到第 5 页后再 `next` 会循环到第 1 页；翻到第 1 页后再 `prev` 会循环到第 5 页。
3. 部署时每个设备的 `hub.json` 中 `id` 需唯一，避免消息串线。
